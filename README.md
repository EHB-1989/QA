# QA
This repo contains all the tests example and exercises used in QA training: unit tests, integration tests,e2e,... 

## Tests de performance

1. Créer un fichier Python pour le script de test locustfile.py
2. Définir le comportement
3. Exécuter locust en exécutant la command locust
4. Ouvrir le navigateur et accéder à http://localhost:8089
5. Spécifier le nombre d'utilisateur à simuler le taux de hachage
